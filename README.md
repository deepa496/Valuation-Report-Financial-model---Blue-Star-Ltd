# Valuation-Report-Financial-model---Blue-Star-Ltd
Equity valuation of Blue Star Ltd (NSE: BLUESTARCO) using a 10-year DCF model, relative valuation, and Monte Carlo simulation - built as an academic financial modeling project.

An academic equity research project valuing **Blue Star Limited (NSE: BLUESTARCO)**, 
a leading Indian HVAC and cooling solutions company, valuation techniques.

## Overview
- **Methodology:** 10-year FCFF DCF model (FY27E–FY36E) with mid-year discounting convention
- **WACC:** 14% | **Terminal Growth:** 5%
- **Relative Valuation:** Peer comparison using Voltas and Amber Enterprises as primary comps
- **Monte Carlo simulation:** Intrinsic value distribution

## Key Outputs
Football field valuation chart, DCF bridge, WACC build, sensitivity grids, and 
relative valuation summary — screenshots included below.
