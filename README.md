# Financial Model & Valuation Report - Blue-Star Ltd
Equity valuation of Blue Star Ltd (NSE: BLUESTARCO) using a 10-year DCF model, Relative valuation (Trading Comps), and Monte Carlo simulation - built as an academic financial modeling project.

## Project Overview
This project evaluates Blue Star Limited. an Indian HVAC and cooling solutions company using 
multiple valuation techniques.

**Valuation Methodologies**
- **DCF Valuation:** 10-year FCFF DCF model (FY27E–FY36E) with mid-year discounting convention
- **WACC:** 14% | **Terminal Growth:** 5%
- **Relative Valuation:** Peer comparison using Voltas and Amber Enterprises as primary comps
- **Monte Carlo simulation:** Intrinsic value distribution
